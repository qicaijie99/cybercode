# Official IM icons

These assets are bundled locally so the desktop UI does not depend on external image hosts.

- `weixin.svg`: mark published in the header of `https://weixin.qq.com/`
- `qq.png`: `https://static-res.qq.com/static-res/imqq/qq-logo.png`
- `feishu.png`: favicon published by `https://www.feishu.cn/`
- `dingtalk.svg`: DingTalk mark from Ant Design Icons (`@ant-design/icons`, MIT)
- `telegram.svg`: `https://telegram.org/img/website_icon.svg`

The product names and marks belong to their respective owners.
