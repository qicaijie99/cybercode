# CyberCode v1.1.8

## Highlights

- Expands model access with first-class OAuth connections, API-key providers, model aggregation sites, local runtimes, verified no-key models, and configurable intelligent routing.
- Turns Code Graph into a direct Knowledge Space with automatic project indexing, symbol and impact search, visual exploration, and graph-first agent guidance.
- Adds background-managed Computer Use runtimes and native desktop helpers so users can install, repair, and start computer control without manual Python setup.
- Adds official Weixin, QQ, and DingTalk integrations alongside Telegram and Feishu, with visible setup guides and native platform icons.

## Desktop Experience

- Makes local conversation switching faster and more resilient without treating local history as a network dependency.
- Improves streaming text order, message sizing, scroll stability, command activity effects, bubble geometry, and compact low-resolution layouts.
- Adds editable steering queues, drag-and-drop attachments, region screenshots, selected-text actions, and consistent chat-width controls.
- Corrects per-turn and session token accounting and keeps token-optimization switches reversible at the global level.

## Intelligence And Portability

- Persists compact project memories from temporary conversations and evaluates self-evolution learning every six user messages while preserving explicit immediate-memory requests.
- Adds bidirectional migration for supported coding agents, including skills, memories, rules, and project metadata.
- Adds goal-mode tools, smarter provider-aware model handling, current context-window defaults, and route-aware model selection for scheduled tasks and chats.
- Keeps Code Graph, RTK, agent-browser, Lite cleanup, and intelligent pruning independently configurable.

## Reliability

- Uses atomic local-state writes for usage analytics and stronger cache invalidation for RTK settings.
- Improves provider error mapping, OAuth runtime isolation, attachment fallback behavior, Windows shell fallback, and long-running response visibility.
- Signs the embedded macOS Computer Use helper with the same Developer ID certificate used by the desktop app before notarization.
- Validates the final packaged Code Graph schema and grammars, RTK runtime, agent-browser runtime, Computer Use helper, and CyberCode sidecar on every release target.

## Distribution

- Cloud builds cover macOS Apple Silicon, macOS Intel, Linux x64, and Windows x64.
- Every platform includes a ZIP download alongside its normal DMG, DEB, or NSIS installer and updater artifacts.
- Automatic updater manifests include direct GitHub downloads and the configured mirror fallbacks.

## Verification

- Passed 1,004 root tests, 604 desktop tests, 329 IM adapter tests, 14 sidecar tests, and 12 analytics-server tests.
- Passed desktop TypeScript validation, production web build, VitePress documentation build, workflow validation, staged-content checks, and credential scans.
