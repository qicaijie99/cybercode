# CyberCode v1.1.13

## Highlights

- Reworks the model and routing workspace for compact desktop windows, with stable four-tab navigation, responsive provider grids, and dialogs that remain usable at low resolutions.
- Separates custom providers from local runtimes and places custom connections first, while preserving every existing provider and model configuration.
- Adds a unified Data Migration workspace for Agent imports and complete USB-based CyberCode portability across macOS ARM64, macOS Intel, Windows x64, and Linux x64.
- Ships a verified private Computer Use runtime archive inside every desktop package, so normal users do not need to install Python or prepare dependencies manually.

## Providers And Routing

- Fixes model-level branding so DeepSeek and other child models use their own logo instead of inheriting an unrelated provider logo.
- Standardizes model, API format, Web Cookie, and media-provider selectors with the same keyboard-accessible dropdown component.
- Adds localized, provider-specific Web Cookie credential instructions, exact field names, safe clipboard import, and clearer security guidance.
- Keeps provider filtering useful with an empty search query and improves compact layouts for intelligent routing, Agent Node, status metrics, and route actions.
- Keeps custom, official API, aggregator, OAuth, Web Cookie, media, and local catalogs distinct and consistently ordered.

## Data Migration And Portability

- Combines Agent migration and USB portability in one keyboard-accessible page while retaining compatibility with the previous migration route.
- Copies settings, sessions, skills, plugins, selected projects, portable path metadata, launchers, and optional application packages into an atomic portable bundle.
- Maps project references across drive letters and mount points so the same portable data can reopen projects on Windows, macOS, and Linux.
- Adds data-only fallback when portable application assets are temporarily unavailable and keeps downloader diagnostics out of user-facing localized messages.
- Prevents filesystem roots, the user profile, and directories containing CyberCode configuration from being mistaken for projects.
- Fixes first-run profiles, updates to an existing portable directory, Windows launcher argument forwarding, staging paths, checksums, and rollback behavior.

## Computer Use And Distribution

- Packages the verified Computer Use runtime as an opaque archive and safely installs it into private app data on first use.
- Validates the archive format, platform target, size, SHA-256 checksum, extraction paths, Python executable, and required imports before activation.
- Keeps the packaged archive outside native signing and dependency scans, avoiding macOS notarization failures and Linux AppImage library detection.
- Preserves atomic activation, rollback, legacy runtime compatibility, and managed network download fallback.
- Fixes Windows runtime archive creation under Git Bash by converting runner paths before invoking `tar`.
- Adds Linux AppImage and Windows portable ZIP assets, plus a checksummed `portable.json` manifest used by USB migration.
- Publishes a standard ZIP download for every supported desktop platform alongside installers and updater manifests.

## Reliability

- Prevents stale generated Computer Use resources from leaking into local or release builds when embedding is disabled.
- Preserves portable Code Graph, scheduled-task, and session project paths without changing unrelated local paths.
- Improves migration state reuse, compact-window overflow handling, startup resource validation, and token-usage control styling.
- Adds multilingual Data Migration documentation and updates provider-routing guides to match the final catalog structure.

## Verification

- Passed 1,424 root service, adapter, routing, migration, and utility tests.
- Passed all 730 desktop Vitest cases, TypeScript checks, production build, 17 sidecar tests, Rust checks, analytics tests, and multilingual documentation build.
- Passed 640x600 and 800x600 real-browser checks for provider catalogs, routing subpages, Web Cookie dialogs, and both migration tabs without horizontal overflow or console errors.
- Verified a real bundled runtime archive through offline extraction and Python dependency validation with zero network requests.
- Validated GitHub Actions syntax, release asset rules, portable archive generation, whitespace, and packaged resource checks.
