# 微信接入

> 通过腾讯官方 iLink 通道扫码连接，不需要公网服务、反向代理或额外插件。

## 1. 发起扫码连接

1. 打开 CyberCode 桌面端。
2. 进入 `设置 -> IM 接入 -> 微信`。
3. 点击「扫码连接」。
4. 使用手机微信扫描弹窗中的二维码，并在手机上确认。

二维码过期时 CyberCode 会自动刷新。如果手机微信显示校验数字，在桌面弹窗中输入这组数字并提交。

## 2. 开始对话

显示「微信已连接」后，CyberCode 会自动启动 iLink 长轮询。可以直接发送文本，或先发送：

```text
/projects
```

选择工作项目。使用 `/new` 开始新会话，使用 `/status` 查看当前执行状态。

## 3. 附件处理

- 图片：在本机从微信 CDN 下载并解密，作为图片交给当前模型。
- 文件和视频：解密到 `~/.cyber/im-downloads/weixin/`，把本地路径交给 Agent。
- 语音：微信提供转写时优先使用转写；没有转写时保留为本地 `.silk` 文件。

临时附件会由 CyberCode 自动清理。

## 4. 停用或断开

- 关闭通道开关：保留本机凭据，但不再收取微信消息。
- 点击「断开」：删除本机 iLink 凭据和已配对记录。

## 常见问题

### 一直停在等待扫码

先确认手机网络正常。关闭弹窗后重新点击「扫码连接」，不需要手动清理配置。

### 显示已绑定，但本机没有凭据

这表示微信端仍记得旧绑定，而本机配置已被删除。在微信端解除旧绑定后重新扫码。
